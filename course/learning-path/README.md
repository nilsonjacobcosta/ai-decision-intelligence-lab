# Learning Path

Área destinada ao registro do percurso de aprendizagem que dará origem aos modelos e componentes deste laboratório.

Os conteúdos devem ser registrados de forma progressiva, preservando:
- conceito original;
- exemplo utilizado no estudo;
- interpretação;
- abstração reutilizável;
- limitações;
- possíveis aplicações.
